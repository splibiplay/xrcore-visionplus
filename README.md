Vision intelligence module for XRCore spatial understanding workflows.

## Published foundation (Unity Asset Store)

Install the core SDK from Unity first, then add this module via Git URL:

- [XRCore – Event-Driven AI Framework for Unity XR](https://assetstore.unity.com/packages/tools/ai-ml-integration/xrcore-event-driven-ai-framework-for-unity-xr-366852)

## Value in 2 Minutes

1. Install XRCore SDK + VisionPlus module.
2. Add VisionPlus runtime bridge to the demo scene.
3. Trigger a mock perception event.
4. Verify event bus publication and context writeback.

## What It Adds

- vision/perception contract constants
- profile-driven confidence gates
- runtime bridge for scene intelligence events
- standardized state keys for downstream modules
